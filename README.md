# 研习 · Equity Research Tutor

本地股票研究与学习工作台。自主选择公司，阅读官方财报，记录自己的观察、假设和反方证据，并通过估值与复盘逐步积累研究能力。

当前版本：**V1.1.1**，基于 Equity Research Tutor V1.4.1 方案实现。界面为中文，数据保存在本机。

## 已实现

- 自主维护研究池，按公司保存六阶段研究进度。
- 每日研究任务、断点恢复和应用内提醒，未完成时延续原任务；补齐资料后可建立新的任务资料版本。
- SEC年度10-K标准US-GAAP事实提取、原始JSON存档和来源记录。
- 手动证据录入、三层教学提示、回答版本及待复习概念。
- 三情景FCFF估值、WACC与增长率敏感性、反向DCF。
- Markdown与JSON导出；配置导出运行库后可生成带公式和原生数据表的Excel。
- 使用本机已登录Codex的AI导师对话和回答点评；按公司保存独立对话，并读取已提交的研究回答。
- 财报中英对照：上传PDF/TXT/HTML、粘贴文字或读取SEC原文，分段翻译、中文/数字/币种/单位及常见科目检查、暂停续翻与保留历史的选段重译。
- 自动备份、手动备份、备份上传下载与恢复，以及运行环境检查。

## 运行

主程序只依赖Python标准库，要求Python 3.11或更新版本。

Windows双击 `启动研习.vbs` 或 `启动研习.cmd`。也可在项目目录运行：

```powershell
python app.py --open
```

打开 [本地工作台](http://127.0.0.1:8765)。关闭网页后后台服务可能继续运行；在“偏好设置”中退出本地服务。

首次使用在“公司档案”添加并选择股票，在设置中填写SEC访问身份，再获取官方资料。提醒需手动启用；电脑与本地服务运行时才能执行到期任务。

## Codex AI

在本机安装并登录Codex CLI，然后在工作台设置选择“本机Codex”，启用AI。模型名可留空使用Codex默认模型，也可指定账号支持的模型。

调用通过Codex自身的登录完成，不需要将密码或登录令牌填写到工作台。使用现有Codex账号的额度；不会在调用失败时自动切换到API计费。工作台对话与Codex当前聊天分开保存，不自动继承聊天历史。

接入已在Codex CLI `0.166.0-alpha.5.1`上验证。程序用非交互、临时会话调用文字模型，并关闭命令执行、插件、电脑操作及主动搜索能力。更换CLI版本后可能需要检查参数兼容性。

可用 `ERT_CODEX_PATH` 指定Codex可执行文件。自定义模型接口是单独选项，密钥通过 `ERT_MODEL_KEY` 环境变量提供。

## Excel导出

Excel导出使用Codex随附的Node.js与 `@oai/artifact-tool`。它们不随本仓库分发；缺少该运行库时，主程序和Markdown/JSON导出仍可使用。

程序会查找当前用户的Codex运行库。若运行库位置不同，用 `ERT_RUNTIME_MODULES` 指定其 `node_modules` 路径，同时保证Node.js可用。

Excel单一模型可切换情景重算，敏感性使用原生双变量数据表。并列三情景摘要明确标记为导出时快照；修改假设后应重新计算、导出。已与Python核对三情景及25个敏感性组合，尚未在桌面Excel中人工验证重算。

## 数据与隐私

运行后生成的 `data/`、`exports/`、数据库、日志、依赖目录和本机快捷方式均已加入忽略清单，不纳入版本管理。备份研究记录时，先退出服务，再另行备份 `data/`。

只有主动向AI发送问题或请求点评时，才发送界面说明范围的研究上下文。Codex登录凭据由Codex自身管理，项目不复制它们。

## 验证

```powershell
python -m unittest discover -s tests -v
```

79项自动检查覆盖估值、历史记录、提醒、资料筛选、访问校验和AI接入；自动检查使用隔离数据和模拟响应，不会调用真实付费模型或修改正式研究档案。AI接入另做过真实连接验证。

## 财报中文翻译

在“财报中文阅读”中导入报告，先翻译一个段落核对质量，再按需安排全文翻译。支持文字型PDF、UTF-8 TXT/HTML、粘贴文字，以及SEC Archives原始HTML链接。PDF读取优先使用当前Python的`pypdf`，也可使用现有Codex随附Python；其他环境可运行`python -m pip install -r requirements-optional.txt`。

长报告逐段保存，可暂停或中断后续翻；每段会检查是否确有中文译文，并对数字、币种、单位及可识别的科目金额做基础检查，差异会提示核对；这些规则不能证明译文语义完全正确。翻译使用所选Codex账号额度，扫描件需先OCR，复杂表格请对照原件。机器译文不作为已验证财务事实。

运行时每天自动备份一次，保留7份自动备份。设置页可另建手动备份、下载或上传ZIP备份并恢复；恢复前会另存当前状态。创建、导入和恢复共用最多5000个条目及250MB展开容量限制，包含清单；超限会明确拒绝，不标为成功。

## 当前范围

自动财务提取限定非金融美股的年度10-K标准标签。季度/TTM自动转换、重述调节、自定义XBRL标签及完整的跨公司教学迁移尚未实现。估值使用简化的增长/ROIC再投资模型，适用条件及口径限制见使用说明。

实际SEC连接需要用户提供访问身份并验证网络；连续多日运行需要选股并启用后观察。第一版不包含自动交易。
